# Akshat Pawar | Portfolio

My personal portfolio website built with React, showcasing my projects, 
skills, and experience.

🔗 **Live:** [akshatpawar.pages.dev](https://akshatpawar.pages.dev)

## Stack

- **React**: component-based UI
- **CSS**: custom styling per component, no UI library
- **Resend**: contact form email delivery
- **Cloudflare Pages**: hosting and deployment

## Sections

- Header & Hero
- About Me
- Experience
- Services
- Portfolio / Projects
- Testimonials
- Contact
- Footer

## Features

- Dark mode support
- Responsive design
- Contact form with email delivery via Resend
